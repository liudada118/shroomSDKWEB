# 怎么用 AI 来开发

你手上这个 SDK，只负责一件事：**把压力传感器的数据稳定地送到你手上，并且画出来。**

至于做成什么——游戏、康复训练、坐姿提醒、压力曲线——那部分不在 SDK 里，
但你不需要自己写，让 AI 写就行。这篇讲的就是怎么让 AI 写对。

不需要会编程。但**要能照着步骤操作**，比如解压文件、双击运行、复制粘贴。

---

## 一、先确认设备是好的（5 分钟，别跳过）

**先别急着找 AI。** 万一后面出问题，你得能分清是「AI 代码写错了」还是「设备本来就没连上」。
先跑通官方示例，后面就有了一个确定的参照。

1. 解压 SDK，按你的系统启动：

   | 系统 | 怎么启动 |
   | --- | --- |
   | Windows | 双击 **`start-demo.bat`** |
   | macOS / Linux | 打开「终端」，`cd` 到解压出来的文件夹，敲 **`sh start.sh`** |

   > macOS 上**双击 `.sh` 文件是没用的**，系统会用文本编辑器打开它，不会运行。
   > 必须在终端里敲命令。

2. 会自动弹出浏览器（**必须是 Chrome 或 Edge**）
3. 插上设备，点「**连接设备**」，在弹出的列表里选中你的设备
4. 应该看到一片点阵，用手按上去会鼓起来、变颜色

看到了就说明设备、驱动、浏览器全都正常，可以进下一步。

看不到？先点「**用模拟数据**」试试：

- **模拟数据能动** → 设备或驱动的问题，看下面这张表
- **模拟数据也不动** → 浏览器不对（Safari / Firefox 不支持），换 Chrome

设备连不上时，先按系统对照一下：

| 系统 | 最常见的原因 |
| --- | --- |
| Windows | 没装 USB 串口驱动。装 CH341SER，然后在设备管理器里确认出现了 COM 口 |
| macOS | 较新的系统自带驱动，插上后设备名形如 `/dev/tty.usbserial-*`；没有就装一下 CH34x 驱动 |
| Linux | 驱动通常自带，但**当前用户不在 `dialout` 组**，打开串口会 Permission denied。执行 `sudo usermod -aG dialout $USER`，然后重新登录 |

还不行就翻 SDK 文件夹里 `README.md` 的完整排错表。

> **没有设备也能全程往下走。** 「用模拟数据」会生成假数据，
> 写代码、调界面、给 AI 测试都够用，等设备到了改一行就能换成真的。

## 二、把说明书交给 AI

SDK 里有一份专门写给 AI 读的文件：

```
AI-CONTEXT.md
```

**把这个文件整个发给 AI。** 按你用的工具选一种：

| 你用的 | 怎么做 |
| --- | --- |
| ChatGPT / Claude 网页版 | 把文件直接拖进对话框 |
| Claude Code / Cursor / Copilot | 把 SDK 文件夹放进项目，说「先读一下 `sdk/AI-CONTEXT.md`」 |
| 只能粘文字的 | 用记事本打开，Ctrl+A 全选，Ctrl+C 复制，粘进去 |

**这一步不能省。** 不给这个文件，AI 会凭空猜函数名字——写出来的代码看着挺像回事，
一跑就报错，然后你和它会在错误的方向上来回折腾很久。

> 换了新对话、或者聊太久 AI 开始犯迷糊时，**把文件重新发一次**。
> AI 记不住之前对话里的东西。

---

## 三、说清楚你要什么

发完文件，用大白话描述就行：

> 我有一个压力传感器 SDK，说明在我刚发给你的文件里。
> 帮我做一个网页：屏幕上有个小球，我按传感器的哪个位置，小球就移动到哪，
> 按得越重球越大。

**说清这四件事，返工会少很多：**

1. **要看到什么** —— 一个页面？一个数字？一条曲线？一个游戏？
2. **什么条件触发什么** —— 按到多重算数？持续多久？
3. **在哪跑** —— 网页就行，还是要打包成能双击的桌面软件？
4. **有没有设备** —— 没有的话加一句「**先用模拟数据**」，AI 就会写成不插设备也能调的版本

最后可以补一句，能省掉一轮返工：

> 请写成单个 HTML 文件，我放进 sdk/web/ 目录里就能直接打开。

## 四、常见需求，直接抄

改改细节发给 AI 就能用：

**看数据**
> 做一个页面，左边热力图，右边实时显示最大压力、受力面积、重心坐标三个数字。

**画曲线**
> 热力图下面加一条曲线，显示最近 30 秒的最大压力变化。

**做判断**
> 当压力超过 0.6 并持续 2 秒，页面变红并播放提示音。

**分区统计**
> 把传感器分成左右两半，分别显示两边的压力总和，用两根柱子表示。

**录制回放**
> 加录制和回放按钮，录制时数据存在内存里，回放时按原速播放。

**小游戏**
> 做一个打地鼠：随机位置出现一个圆点，我按中那个位置就得一分。

**坐姿提醒**
> 显示热力图，如果重心偏左或偏右超过 20% 并持续 10 秒，弹提示让我坐正。

## 五、AI 写好的代码怎么跑起来

AI 一般会给你一个 `.html` 文件。

> ### ⚠️ 不能双击打开 HTML 文件
>
> 浏览器规定：**串口只在 `https` 或 `localhost` 下才能用**。
> 双击打开文件时地址栏是 `file://`，串口功能直接不存在——
> 这是浏览器的硬规定，**没有任何办法绕过**，AI 也绕不过。
>
> 症状很好认：页面能打开、按钮能点，但点「连接设备」毫无反应。

**正确做法：**

1. 把 AI 给你的文件放进 **`sdk/web/`** 文件夹里
2. 照常双击 `start-demo.bat`
3. 浏览器打开后，把地址栏末尾的 `index.html` 改成你的文件名

比如 AI 给了 `game.html`，放进 `sdk/web/`，然后访问：

```
http://localhost:5178/game.html
```

> 如果 5178 被别的程序占用了，启动时会自动往后挑 5179、5180……
> **以黑窗口里实际打印的地址为准**。

## 六、出问题了怎么跟 AI 说

代码一次跑通是少数情况，来回两三轮很正常。关键是**把具体现象告诉它**：
页面白屏或按钮没反应，按 **F12** 打开 Console，把**红色报错整段**复制给它；
数据不对，说清「我期望看到什么，实际看到什么」。

万能句式：

> 报错是：（原样贴上报错）
> SDK 说明在我前面发的 AI-CONTEXT.md 里，请对照着看是哪里用错了。

**AI 改了三四轮还是不行**，别继续绕。开一个新对话，重新发一遍 AI-CONTEXT.md，
把需求说得更具体些——通常比在旧对话里死磕快。

## 七、几件事先说明白

**数据是 0~1 的相对值，不是 kPa、不是公斤。**
这是最容易误会的一点。SDK 给的是传感器原始读数归一化后的值，
要换算成真实物理单位，需要每台设备各自的标定数据，那不在这个 SDK 里。

**如果 AI 给你写出了「12.5 kPa」这种，那是它编的，数字不准。**
需要真实单位请联系官方技术人员获取标定数据。

**只有 Chrome 和 Edge 能连串口。** Safari 和 Firefox 没这功能。

**SDK 只管连接、取数、显示三件事。** 曲线、回放、算法这些由 AI 在它之上帮你写。

**改坏了不要紧。** 你自己写的东西单独放一个文件夹，别和 SDK 原有文件混在一起。
真弄乱了，重新解压一份 SDK 就行。

## 八、想深入了解

SDK 文件夹里还有三个文件：

- `README.md` —— SDK 完整说明和排错表
- `AI-CONTEXT.md` —— 给 AI 看的那份，你自己想看也行，写得挺全
- `index.d.ts` —— TypeScript 类型定义，用 TS 时 AI 会需要
