# 怎么用 AI 来开发

这个 SDK 只负责把传感器数据稳定地送到你手上。至于要做成什么——
游戏、康复训练、坐姿监测、体重秤、压力曲线——那是你的部分。

自己不写代码也行，让 AI 写。下面是完整流程。

---

## 一、先把设备跑通（5 分钟）

**别急着找 AI**，先确认设备是好的，不然后面出了问题分不清是代码错了还是设备没连上。

1. 双击 `start-demo.bat`（macOS / Linux 用 `sh start.sh`），浏览器会自己打开示例页面
2. 插上设备，点「连接设备」，在弹出的列表里选中你的设备
3. 应该能看到一片点阵，按上去会鼓起来变色

看不到？照着 [README.md](README.md) 最后那几张排错表对，那里把每种情况都列了。

> **没有设备也能往下走**：点「用模拟数据」，一样能看到效果，写代码时也能用。

---

## 二、把 SDK 说明交给 AI

SDK 里有一个专门写给 AI 看的文件：

```
AI-CONTEXT.md
```

**做法：把这个文件整个发给 AI。**

- ChatGPT / Claude 网页版：直接把文件拖进对话框
- Claude Code / Cursor / Copilot 这类在编辑器里的：SDK 解压到项目里，
  跟它说「先读一下 `sdk/AI-CONTEXT.md`」
- 只能粘文字的：用记事本打开，全选复制，粘进去

这一步不能省。不给它这个文件，AI 会凭空猜 API 名字，写出来的代码跑不了。

---

## 三、描述你想要什么

给 AI 发完文件，接着说人话就行。比如：

> 我有一个压力传感器 SDK，说明在上面那个文件里。
> 帮我做一个网页：屏幕上有一个小球，我按传感器的哪个位置，
> 小球就跟着移动到哪；按得越重球越大。

或者：

> 帮我做一个坐姿监测页面：显示热力图，
> 如果重心偏左或偏右超过 20% 持续 10 秒，就弹个提示让我坐正。

或者：

> 帮我加一个录制功能，能把 30 秒的数据存下来，之后可以重新播放。

**描述得越具体越好。** 说清楚这几件事，返工会少很多：

- 想看到什么（一个页面？一个数字？一条曲线？）
- 什么条件下发生什么（按到多重就怎样？）
- 在哪里跑（网页？还是打包成桌面程序？）

---

## 四、常见的几类需求，可以直接抄

把下面这些话直接发给 AI，改改细节就能用：

**看数据**
> 做一个页面，左边是热力图，右边实时显示最大压力、受力面积、重心坐标三个数字。

**画曲线**
> 在热力图下面加一条曲线，显示最近 30 秒的最大压力变化。

**做判断**
> 当压力超过 0.6 并持续 2 秒时，页面变红并播放提示音。

**分区统计**
> 把传感器分成左右两半，分别显示两边的压力总和，用两根柱子表示。

**录制回放**
> 加录制和回放按钮，录制时把数据存在内存里，回放时按原速播放。

**做成小游戏**
> 做一个打地鼠：热力图上随机位置出现一个圆点，我按中那个位置就得一分。

## 五、AI 写出来的东西怎么跑

AI 一般会给你一个 `.html` 文件或者几个 `.js` 文件。

**关键一点：不能双击打开 html 文件。**

浏览器规定串口只在 `https` 或 `localhost` 下开放，双击打开是 `file://`，
串口用不了——这是浏览器的硬规定，任何办法都绕不过去。

正确做法：把 AI 给的文件**放进 SDK 目录里**，然后照常双击 `start-demo.bat`，
在浏览器地址栏把 `index.html` 换成你的文件名。

比如 AI 给了 `game.html`，放进 `sdk/web/`，
然后访问 `http://localhost:5178/game.html`。

## 六、出问题了怎么跟 AI 说

代码跑不起来是常事，把**具体现象**告诉 AI，别只说「不行」：

| 情况 | 这样跟 AI 说 |
| --- | --- |
| 页面白屏 | 按 F12 打开 Console，把红色报错整段复制给它 |
| 按钮点了没反应 | 同上，看 Console 有没有报错 |
| 有画面但数据不对 | 说清楚「期望看到什么，实际看到什么」 |
| 连不上设备 | 先用示例页面确认设备本身是好的，再说 |

一句很管用的话：

> 报错是：（把报错原样贴上）。SDK 的说明在我前面发给你的 AI-CONTEXT.md 里，
> 请对照着看是哪里用错了。

## 七、几件事先说明白，免得白折腾

**数据是 0~1 的相对值，不是 kPa、不是公斤。**
要换算成物理单位需要每台设备各自的标定数据，那不在这个 SDK 里。
如果 AI 给你写出了「XX kPa」，那是它编的，不准。需要真实物理单位得找设备厂商要标定数据。

**只有 Chrome 和 Edge 能连串口。** Safari 和 Firefox 没有这个功能。

**SDK 里没有曲线、回放、算法这些。** 它只管连接、取数、显示。
上面那些都要 AI 帮你现写——这是设计成这样的，不是缺功能。

**改坏了不要紧。** SDK 本身不会被改动，重新解压一份就行。
建议你自己写的东西单独放一个文件夹，别和 SDK 的文件混在一起。
