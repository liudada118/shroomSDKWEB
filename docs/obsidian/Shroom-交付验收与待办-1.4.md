## 两条验收

- 标准 SDK 发布
	- 验收对象
		- 固定发行包与同版文档
		- 声明的最小支持路线
		- 标准接口与参考集成
	- 发布依据
		- 标准检查完成
		- 结果与证据可追溯
		- 通过范围与限制明确
	- 发布边界
		- 不等待单个客户业务上线
		- 专项通过不自动证明通用支持
		- 客户发现的通用缺陷纳入发布判断
- 客户项目交付
	- 验收对象
		- 客户固定环境与设备
		- 客户选择的交付模式
		- 项目内约定的接入任务
	- 验收阶段
		- 最小集成验证
		- 客户环境试运行
		- 正式使用交付
		- 本轮选择具体阶段
	- 项目依据
		- 引用标准版本证据
		- 补做客户环境与接入检查
		- 专项能力另记责任与结果
- 三层结果分别判定
	- SDK 契约
		- 数据格式、映射与含义
		- 约定的连接生命周期
		- SDK 方负责缺陷处理
	- 客户接入
		- 数据进入客户实际处理路径
		- 客户代码正确调用与释放
		- 双方按接口边界定位问题
	- 客户业务效果
		- 默认作为应用效果观察
		- 客户负责自身业务逻辑
		- 业务失败不自动判 SDK 失败
		- 专项服务仅验收明确承担部分
- 结果示例
	- 数据正确但客户阈值错误
		- SDK 检查可通过
		- 接入或业务项按原因处理
	- SDK 映射错误导致业务异常
		- SDK 对应检查不通过
		- 修复后重验受影响项目
	- 客户暂未安排业务上线
		- 项目阶段如实登记
		- 不改写标准版本验证结论

## 支持组合、交付模式与责任

- 最小支持路线
	- 本轮产品、语言与环境：待填
	- 每条路线给出支持状态
	- 已承诺的必要产品能力进入门槛
	- 不要求全语言功能对等
	- Python 直接接入承诺须有产品能力
	- 未核实封装不标为已支持
- 支持组合
	- 标准支持
		- 对应任务已验收
		- 有维护责任与已知限制
	- 客户专项
		- 有范围、责任人与节点
		- 验收前不标为标准支持
	- 评估中或范围外
		- 交付前说明当前状态
		- 试用可运行不等于支持承诺
	- 承诺变更
		- 不因失败事后移出范围
		- 调整已承诺范围须客户确认
- 证据与版本维护
	- 证据仅覆盖记录中的包与支持组合
	- 固件、映射或依赖变化时评估影响
	- 涉及数据或连接行为时补做相关验证
	- 未经评估不沿用已通过结论
	- 维护期限、缺陷响应与迁移安排待填
	- 升级说明受影响字段、工件与接口
	- 用同组参考样本检查升级影响
	- 回退所需旧包与配置可获得
	- 无法回退的变化提前说明
- 交付模式
	- 自助接入
		- 文档、例程与标准支持
		- 额外人工救援单独登记
	- 辅导接入
		- 约定辅导任务与交付物
		- 客户负责自身应用实现
	- 集成服务
		- 明确由交付方实现的部分
		- 明确业务结果与验收边界
	- 每种模式
		- 客户前提与完成条件
		- 包含与超范围事项
		- 服务投入与处理入口
- 专项需求归属
	- 标准核心
		- 有跨客户复用依据
		- 评估 API 与回归影响
		- 落实持续维护投入
	- 独立适配
		- 边界与依赖明确
		- 独立记录版本和负责人
	- 客户代码
		- 客户业务规则留在应用侧
		- 约定代码交付与维护归属
	- 承诺前确认
		- 选定归属与方案
		- 估算开发、验证与维护投入
		- 识别分支与升级负担
		- 不默认每个项目修改核心
- 支持投入
	- 预算可包含在硬件交付中
	- 不以独立付费许可为前提
	- 区分计划服务与临时救援
	- 明确投入上限与超额处理
	- 预计超额时重新确认范围
- 责任分工
	- 产品：路线、承诺与验收范围
	- SDK 与协议：数据、连接与缺陷
	- 测试：条件、结果与证据
	- 发布与文档：包、说明与入口
	- 客户：业务逻辑与环境配合
	- 每项填写具体负责人
	- 不以职能名称代替实际认领

## 可执行验收清单

- 基础集成门槛
	- 适用于本轮承诺的最小路线
	- 数据含义错误阻断对应交付
	- 未通过项修复或协商范围处理
- 安装与入口
	- 仅用发行包和同版文档
	- 在干净客户环境安装与导入
	- 产品、语言与环境前提可预判
	- 固定包标识与依赖条件
	- 最小例程产生真实数据
- 数据与最小集成
	- 核对型号、左右手与映射
	- 检查字段、单位与统计范围
	- 原始值与归一化值可区分
	- 旧兼容统计不冒充全手统计
	- 数据进入实际应用处理路径
	- 已知样本得到预期结构结果
	- 不只以控制台打印作为完成
- 连接与运行
	- 无新数据和断连可识别
	- 按路线约定执行恢复
	- 取消订阅与资源释放可验证
	- 退出后能再次连接
	- 在约定负载和时长下检查
	- 仅承诺实测覆盖的条件
- 消费与帧使用
	- 最小正确用法有可运行例程
	- 异步保留帧的方式可核对
	- 默认消费策略及限制明确
	- 慢消费者检查按任务需要选择
	- 不要求先实现全部可选模式
- 选配能力门槛
	- 网页展示
		- 连接与数据更新状态可辨
		- 色阶与数值范围可解释
	- 文件采集
		- 起停、重试与状态可解释
		- 网页重开可发现活动任务
		- 文件完成与数据质量分开检查
		- 文件、记录 ID 与字典对应
	- 客户专项
		- 按已确认的专项清单验收
		- 明确不覆盖的能力
	- 仅在承诺该能力时适用
	- 高级契约不全部列为 P0
- 专项业务效果
	- 仅对明确承担的服务结果验收
	- 约定输入、预期结果与责任
	- SDK 问题与客户业务问题分开
- 检查记录要求
	- 条件与预期结果
	- 实际结果与证据
	- 通过、失败或未覆盖
	- 失败原因与处理结论
	- 修复后重验对应范围
- 最小问题定位
	- 提供包、文档、型号与环境标识
	- 提供复现步骤、预期与实际结果
	- 附连接及最近有效数据状态
	- 附 SDK 可观测错误与质量摘要
	- 用最小例程区分故障来源
	- 不要求先提交完整客户业务项目
	- 指定问题接收人与处理结论

## 指标与支持复查

- 观测单位
	- 一个客户项目的一次接入任务
	- 绑定设备、技术栈与发行包
	- 多项目分开登记，重试不新增
	- 初次集成与升级复验分开
	- 观察前固定范围、模式与阶段
- 整体集成完成率
	- 覆盖全部约定交付模式
	- 已通过任务除以应结算任务
	- 使用事先约定的结算时间
	- 失败、超时与退出保留原因
	- 尚未到期任务另列
	- 按三层责任判定约定验收项
- 自助独立集成成功率
	- 分母为到期的原自助任务
	- 安装与连接失败计入
	- 临时获助后仍保留原分母
	- 事先约定的服务模式不纳入
	- 分子须无额外人工提示
	- 通过本阶段约定的集成检查
	- 辅助后通过只计整体完成
- 时间与尝试
	- 从开始接入到约定验收
	- 总耗时与操作时间分开
	- 等待支持时间单列
	- 首帧仅作为阶段指标
	- 无会话 ID 的失败不漏记
	- 未决任务另列并约定结算
- 选配采集指标
	- 会话完成率单独统计
	- 不替代任务完成率
	- 不等于源端数据完整率
- 支持与使用复查
	- 按项目和交付模式记录耗时
	- 汇总客户数与项目数
	- 计划服务与临时救援分开
	- 对比预计投入与实际投入
	- 区分无使用需求与技术故障
	- 记录部署变化与维护投入
	- 一次验收不等于持续采用
- 结果触发行动
	- 安装失败：改进交付前提
	- 集成卡点：改进例程与字典
	- 生命周期失败：修复对应路线
	- 支持超额：复核模式与预算
	- 专项重复：评估标准化收益
