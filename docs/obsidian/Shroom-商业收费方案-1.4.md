## 一 收费原则与基础权益

- 收费目标假设
	- 保持设备接入门槛可控
	- 为额外人力与持续服务取得收入
	- 在独立软件价值成立后增加软件收入
	- 以客户实际付费与交付毛利验证
- 设备随附权益建议
	- 承诺型号与环境内的产品 SDK
	- 连接、协议解析与点位映射
	- 结构化产品数据与基本生命周期
	- 同版文档与最小集成示例
	- 标准支持的内容和期限明确列示
	- 已交付版本的基础本地使用继续有效
	- 未来新版本与新增服务另列范围
- 既有客户处理
	- 先核对原订单与交付承诺
	- 已包含的能力不追溯另收费
	- 已提供的本地工具按原权益处理
	- 不把既有导出和历史数据读取设为续费门槛
	- 新订单明示随附内容与可选费用
- 不适合作为新增收费项
	- 原承诺范围内的 SDK 缺陷修复
	- 已承诺语言的必要产品能力补齐
	- 使原交付达到约定验收的返工
	- 已包含的标准协议与文档
- 新增需求的判断
	- 新平台或新协议确未包含于原承诺
	- 新客户业务对接超出原责任范围
	- 新现场、培训或服务额度超出原包含范围
	- 报价前明确范围变化及客户确认
- 推荐计费边界
	- 本地基础取数不按帧或普通 API 调用计费
	- 不按传感器通道数设基础解锁费
	- 年度服务到期不使基础取数停机
	- 软件使用权与人工服务期分开说明
- 基础软件需要单列金额时
	- 作为未来新订单整体报价的一项
	- 购前展示硬件、软件与服务总价
	- 明确一次性使用权与维护期
	- 不对既有合同承诺追加费用
	- 单列金额不要求按帧计费或联网解锁

## 二 可组合的收费项目

- A 设备随附基础接入
	- 目标客户
		- 使用标准组合自行集成的设备客户
	- 计费方式
		- 包含在设备交付报价中
		- 不另收基础 SDK 运行费
	- 交付内容
		- 基础权益清单
		- 支持组合与同版资料
		- 包含的标准支持方式与期限
	- 待确认项
		- 标准支持额度与服务时段
		- 维护版本和缺陷处理范围
		- 已购设备及交付主体的使用范围
- B 接入辅导与专项集成
	- 目标客户
		- 需要帮助接入自己的实际项目
		- 需要原范围之外的平台或系统适配
	- 计费单位
		- 按明确范围的项目固定报价
		- 报价绑定型号、环境与交付任务
	- 可售内容
		- 远程接入辅导与培训
		- 客户应用的约定接口对接
		- 新环境或新协议适配
		- 现场部署等明确服务
	- 交付约定
		- 任务、代码或配置交付物
		- SDK、客户接入与业务三层责任
		- 修改范围、验收与维护期
		- 阶段付款与新增需求变更
	- 结束后
		- 约定交付物按约定继续使用
		- 新增范围另评估
		- 原范围未达标不得包装成新需求
- C 年度支持服务
	- 目标客户
		- 已完成接入并需要持续维护支持
	- 计费单位
		- 按客户项目及约定支持范围计年
		- 多项目需要合并时另约覆盖清单
	- 可售内容
		- 约定时段内的技术支持
		- 定期兼容复查与升级协助
		- 固定额度的咨询或培训
		- 双方可承接的响应目标
	- 必填边界
		- 包含工时或服务次数
		- 工作时段与联系渠道
		- 响应目标与处理方式
		- 现场、差旅及超额费用
		- 标准缺陷责任与增值服务的区别
	- 到期后
		- 新增年度服务权益结束
		- 已取得版本的基础使用继续
		- 客户应用与历史数据可继续使用
		- 新兼容承诺与续约另行确认
- D 高级软件与 OEM 商业扩展
	- 当前状态
		- 候选商品，不作为现货销售
		- 付费许可校验尚未实现
		- 未内置能力不能写入现货套餐
	- 高级软件候选
		- 已形成独立价值的分析与工作流
		- 回放、标注、多设备或三维仅为待验证方向
		- 不回收已交付的基础工具权益
	- 软件计费候选
		- 优先选一个可解释的价值单位
		- 如模块与生产部署实例
		- 开发测试、迁移与换机规则同时说明
		- 同一能力不叠加多个不透明单位
	- OEM 单独评估
		- 面向批量嵌入、再分发或白牌交付
		- 可按产品型号或约定出货单位报价
		- 初次适配费用与后续授权分开
		- 正常使用已购设备不自动等于 OEM 收费
		- 分发范围与第三方依赖权限需核对
	- 到期规则先确定
		- 基础接入与已有数据读取保留
		- 高级功能的期限与结束行为明示
		- 不在活动采集中突然截断数据
		- 已出货产品不因支持期结束停机

## 三 定价方法与报价字段

- 当前不设统一金额
	- 缺少设备售价与毛利资料
	- 缺少各类项目实际服务成本
	- 缺少客户付费意愿证据
	- 不能直接以功能数量推定售价
- 项目成本估算
	- 开发与协议适配
	- 测试与兼容回归
	- 部署、培训与项目管理
	- 承诺维护与支持投入
	- 第三方服务与必要外部成本
	- 项目风险与不可复用分支负担
- 报价下限测算
	- 成本记为 C，目标毛利率记为 m
	- 同口径收入下限为 C ÷（1－m）
	- 毛利率不等于成本加价率
	- 示例仅演示计算
		- 预计成本 6000 元
		- 假设目标毛利率 40%
		- 同口径报价下限为 10000 元
		- 不是 Shroom 正式售价或推荐价
	- 再与客户价值和付费意愿比较
	- 客户可接受价格低于下限时调整范围或方案
- 报价单必填
	- 客户主体、项目与采购确认人
	- 商品及随附、选配关系
	- 设备、环境与任务范围
	- 使用权、交付物与服务期限
	- 金额、币种及含税口径
	- 包含额度与超额处理
	- 验收、付款与变更节点
	- 维护、续费、到期与迁移规则
	- 不包含事项与客户配合前提

## 四 收费如何进入产品流程

- 接入入口
	- 明示设备随附权益
	- 明示可选服务及询价入口
	- 已购客户按原权益获取基础 SDK
- 付费服务流程
	- 客户提出额外任务
	- 区分缺陷、既有承诺与新增需求
	- 确认支持状态和服务范围
	- 报价与确认订单
	- 按约定付款及里程碑交付
	- 复用项目验收与问题记录
	- 到期复查与续约
- 早期商业管理
	- 可先用报价单、订单和项目记录
	- 服务收费不以开发许可服务器为前提
	- 记录客户、项目、商品和服务权益
	- 区分已报价、已确认、履行中与已结束
	- 支付、验收与权益状态不能混为一项
- 已确认的授权模型
	- 同一后台管理客户与产品许可证
	- 复用签发、验签、有效期与在线状态逻辑
	- 上位机密钥仅授予上位机产品权限
	- SDK 密钥仅授予 SDK 产品权限
	- 两类产品密钥默认互不通用
	- 同一客户需要两产品时分别签发
	- 授权不等于必须额外收费
		- SDK 密钥可以随设备权益发放
		- 独立报价仍以订单范围为准
- 产品密钥类型已对接
	- 产品字段与签发校验已落地
	- 使用 `productType` 标记所属产品
		- 上位机示例：`shroom-desktop`
		- SDK 示例：`shroom-sdk`
	- 产品类型纳入签名或权威校验结果
	- 客户端核对许可证与自身产品匹配
	- 显示前缀仅方便识别
		- 不以修改前缀改变实际授权
		- 不以客户端自报产品代替许可证核对
	- 产品类型与其他维度分开
		- 在线或离线是校验模式
		- 量产或租赁是业务类别
		- 传感器类型用于协议适配，SDK许可不按型号限制
		- 功能、使用期限与维护期限分别记录
- 旧许可证兼容规则
	- 旧上位机许可证按原范围处理
	- 缺少产品字段不默认授予 SDK 权限
	- `all` 与分类令牌只在所属产品内生效
	- 新增 SDK 不自动扩大旧产品权益
	- 上位机保留原范围，SDK不按传感器型号限制
- SDK 授权接入已实现
	- 共享后台：E:/key
	- 产品类型：上位机与 SDK 分开
	- 旧密钥默认仅上位机
	- SDK 在线载荷使用 sdkFile
	- SDK 离线使用 v5 签名载荷
		- 隔离字段 boundSensorTypes 固定 all
		- 防止旧上位机读取 SDK 码
	- 后台管理已有产品选择
		- SDK不选型号，只配置到期时间
		- 电脑名额、解绑与停用
	- Node、浏览器、Python 已接入
		- 实机入口检查授权
		- SDK不限制传感器型号
		- 同一SDK密钥可使用产品接口与通用串口
		- 在线许可最长 60 秒
		- 限定电脑数量码持续联网
		- 失效关闭采集并保留历史下载
	- 模拟、解析与渲染可直接使用
	- 收费与许可分别管理
		- 许可可随已购设备发放
		- 本次不增加支付与自动扣费
	- 上线前仍需完成
		- 执行后台 0023 数据库迁移
		- 先发布后台，再发布 SDK
		- 用真实密钥与客户设备联调
	- 接入细节见[SDK 授权](C:/sdk/sdk/docs/LICENSE.md)

## 五 上线条件与价格验证

- 首轮优先顺序
	- 先明确基础权益
	- 先试售范围清楚的辅导与集成服务
	- 有持续需求后推出年度支持
	- 有成熟软件价值后再推高级授权
- 正式报价前
	- 核对已有客户承诺
	- 明确交付与技术支持范围
	- 填入成本、额度与责任人
	- 对计划销售能力验证可交付性
	- 确认到期与旧版本行为
- 验证方式
	- 从真实已购客户的额外任务出发
	- 先问其替代方案与内部投入
	- 给出相同范围的清晰报价
	- 记录报价、成交或拒绝原因
	- 记录实际交付工时与变更
	- 少量 B2B 项目先做报价访谈
	- 不把口头感兴趣等同成交意愿
- 业务指标
	- 符合条件客户的付费服务选购率
	- 同口径报价到成交率
	- 项目实际收入、直接成本与毛利
	- 超范围需求与计划外支持投入
	- 到期支持项目的续约情况
	- 基础集成完成率与客户接入时间
	- 不以增加基础接入阻碍换取服务转化
- 风险与处理
	- 客户认为重复收费
		- 在购机报价中列清随附和选配
	- 项目范围无限扩大
		- 报价绑定交付物、验收与变更
	- 支持承诺超过团队能力
		- 先限定时段、额度与组合
	- 高级软件价值不成立
		- 先验证任务和付费意愿
