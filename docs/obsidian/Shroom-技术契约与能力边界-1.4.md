## 数据接入与帧

- 语言与入口
	- 已述快照
		- Node.js：`shroom-sdk/node`
		- 浏览器：包根 Web 入口
		- Python：`shroom_sdk`
		- 当前通过本地 ZIP 交付
		- 未发布公共 npm / PyPI 包
	- 约定
		- 按任务与支持组合标注能力
		- 不默认三种语言能力对等
	- 待核验
		- 产品、固件、系统与运行时组合
		- 模块导入与发行包实际内容
- 产品接入
	- 已述快照
		- Node.js 与浏览器有产品层
		- 手套：`handGloveFullPacket`
		- 手垫：`hand`
		- `connectProduct()` 统一入口
		- 产品层封装波特率、拆帧与映射
		- `connectGlove()` 连接手套
		- `connectHandPad()` 连接手垫
		- 型号与左右手不能自动判断
	- 约定
		- 已支持产品优先使用产品接口
		- 客户不必重新实现协议与映射
		- 左右手与适用配置由使用者确认
- 基础串口与帧
	- 已述快照
		- Node.js：`serialport`
		- 浏览器：Web Serial
		- Python：pySerial
		- 基础查询、连接、读取与关闭
		- 标准 `Frame` 与矩阵映射
		- 网络编码：`shroom.frame.v1`
	- 待核验
		- 拆帧、帧长与诊断的实际行为
		- 各语言产品封装覆盖范围
- Python 能力边界
	- 已述快照
		- 基础串口与矩阵
		- 文字与绘图示例
		- 无产品级快速服务接口
		- 同等录制下载能力未定义
	- 约定
		- 承诺直接接入时须封装产品协议与映射
		- 离线分析可先提供文件读取示例
		- 不默认要求客户跨语言绕行
		- 不要求各语言全功能对等

## 订阅与连接

- 数据订阅
	- 已述快照
		- `device.onData()` 接收产品数据
		- 客户应用直接消费结构化数据
	- 约定
		- 明确调用顺序、取消与重复取消
		- 明确关闭后的回调行为
		- 明确抛错与多订阅者影响范围
		- 明确帧为快照还是借用缓冲
		- 借用缓冲须说明有效期与复制方法
		- 示例不得误保留被覆写的数据
	- 待核验
		- 订阅接口签名与具体错误行为
- 消费与背压
	- 约定
		- 展示优先数据新鲜度
		- 舍弃过期帧须明示策略
		- 逐帧业务与采集不静默改成仅最新帧
		- 超载时明确拒绝、降载或中断
		- 设定缓冲上限、过期阈值与溢出动作
		- 明确慢回调与慢客户端影响范围
	- 待核验
		- 默认模式与可选模式
		- 工作负载、持续时长与容量实测
- 断连与恢复
	- 约定
		- 区分连接状态与数据更新状态
		- 区分同设备恢复与设备替换
		- 端口名不能单独证明设备身份
		- 复核型号、左右手与映射配置
		- 硬件标识仅在可获得时使用
		- 无标识时说明限制并按需重新选择
		- 新旧连接与帧计数重置可区分
		- 旧队列不得混入新连接
		- 恢复首帧不表示无间断延续
		- 恢复连接不保证旧业务无缝续做
		- 客户业务按任务重新确认继续条件
	- 待核验
		- 自动或手动恢复、重试时限与取消
		- 不重复订阅及退出后再次连接
- 资源释放
	- 已述快照
		- `view.destroy()` 释放画面
		- `stream.close()` 断开前端
		- `server.close()` 关闭服务
		- `device.close()` 关闭设备
	- 待核验
		- 活动录制、文件与串口关闭顺序

## 数据含义与质量

- 手套数据
	- 已述快照
		- `side` 表示左右手
		- 原始压力为 256 通道 ADC
		- `fingers` 包含五指命名分区
		- `thumb`、`index`、`middle`、`ring`、`little`
		- 每指主体 4×3 与独立 `pulp`
		- `palm` 共 72 点
		- 行长度为 12、15、15、15、15
		- 分区含 `raw`、`matrix`、`values`
		- 顶层兼容统计仍按旧 195 点矩阵
		- 旧统计不能解释为新分区全手统计
		- IMU 保留原始字节
	- 待核验
		- `pulp` 点数与全部通道用途
		- 未用、保留与重复映射位置
- 手垫数据
	- 已述快照
		- 原始压力为 1024 通道
		- 映射为 32×32 矩阵
		- 提供归一化与基础统计
- 数值与工件
	- 约定
		- 原始 ADC 与相对归一化值分别解释
		- 未标定时不使用 kPa 或牛顿
		- IMU 字节不解释为姿态结果
		- 默认示例不误用旧兼容统计
		- 聚合须说明范围、点数与有效掩码
		- 归一化须说明公式、参数与处理顺序
		- 明确基线、裁剪与无效点处理
		- 不默认跨设备与跨会话可比
		- 工件对应型号、左右手与协议
		- 校验值一致不证明工件适用
		- 映射、掩码与参数可离线取得
		- 以不可变标识或校验值关联工件
	- 待核验
		- API、界面与导出口径一致
		- 参考样本可重建分区与统计结果
- 时间与帧身份
	- 约定
		- 明确时间单位及接收、解析或保存时刻
		- 墙钟用于日期，单调时间用于间隔
		- 同帧在实时流与导出中可对应
		- 设备时间与源序号仅在协议提供时记录
		- 主机时间不冒充真实采样时刻
		- 无设备时间不承诺跨设备同步
- 有效性与更新状态
	- 约定
		- 结构有效按协议能力检查长度、校验与格式
		- 更新新鲜：最近有效帧未超过约定阈值
		- 结构有效不等于物理响应正确
		- 更新新鲜不等于客户业务可用
		- 物理与业务有效性按任务验证
		- 未验证结果保留未知
		- 全零或恒定值本身不等于损坏
		- 坏帧不刷新有效数据更新时间
		- 无效点不静默替换为有效零值
		- 不用“数据正常”概括上述全部状态
- 质量观测
	- 约定
		- 接收、解析、结构有效与保存分开计数
		- 记录解析错误、写入错误与中断区间
		- 可观测的积压、溢出与丢弃需说明
		- 无源序号时不宣称源端无丢帧
		- 单点与多点样本分别验证映射和聚合
	- 待核验
		- 阈值、工作负载与慢消费者验证结果

## 展示、采集与文件

- 两种服务协议
	- 已述快照
		- 快速服务：`serveDevice()`
		- 浏览器客户端：`connectStream()`
		- WS 广播与 `recording.*` 控制
		- 同端口 HTTP 状态与文件下载
		- 默认数据端口 19999
		- 示例网页默认端口 5178
		- `BackendSdkClient` 连接既有主项目后端
		- 该客户端为命名导出
		- 不使用 `Shroom.BackendSdkClient`
		- 不启动既有后端服务
		- 两种后端不是同一协议
	- 约定
		- 纯取数不强制启动服务或网页
		- 本机默认访问边界不等于公网支持
	- 待核验
		- 串口持有、争用及跨机访问范围
- 可选展示
	- 已述快照
		- `createProductView()` 订阅产品数据
		- 手套二维分区图与手垫矩阵热力图
		- `createHeatmap()` 为通用矩阵视图
		- Node.js 终端热力图
		- 未提供三维手模与姿态解算
	- 约定
		- 色阶范围与自适应方式可解释
		- 同色不默认表示相同原始值
		- 展示降频不主动减少录制帧
- 服务端录制
	- 已述快照
		- 录制由 Node.js 快速服务管理
		- 浏览器控制与展示状态
		- 网页关闭后录制继续
		- 重连可查询服务端状态
		- 一次会话一个人工标签
		- `stream.startRecording()` 开始录制
		- `stream.stopRecording()` 停止录制
		- 停止等待文件写完
		- 重启恢复列表并保留中断状态
	- 约定
		- 每个快速服务实例一个活动录制
		- 页面进入先查询活动任务
		- 开始返回唯一记录 ID 并处理重复请求
		- 停止边界、重复停止与超时查询明确
		- 写入失败不报告正常完成
		- 文件完成、数据质量与任务有效性分开
		- 续录须关联中断与配置变化
	- 待核验
		- 多页面控制、断连与退出行为
		- 磁盘写满、取消、空记录及未完成记录规则
- 文件交付
	- 已述快照
		- `listRecordings()` 查询记录
		- `downloadRecording(recordingId)` 按 ID 下载
		- HTTP：`/health`
		- HTTP：`/recordings/{uuid}.csv`
		- HTTP：`/recordings/{uuid}.jsonl`
		- JSONL 本地记录与 CSV 流式导出
		- 记录含 `id`、`label`、`status`
		- 帧数与来源为 `frameCount`、`source`
		- `error` 保留异常信息
	- 约定
		- 不默认下载最近一条
		- 标签与端口不能代替记录 ID
		- 标签描述整段，不等于逐帧动作真值
		- 元数据保留来源、状态、异常与起止时间
		- 关联设备、版本、工件与文件校验信息
		- 未知设备或固件信息明确记为未知
		- CSV 说明行含义、单位、缺失值与编码
		- JSONL 区分解码 ADC 与串口原始字节
		- 不推定能重跑全部协议解析
		- CSV 与 JSONL 帧数及帧身份可核对
